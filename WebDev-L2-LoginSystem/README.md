# WebDev-L2-Login-System

A simple **Login System** built with HTML, CSS, and JavaScript. Provides a basic user interface for login and validation.

---

## 🧮 Features
- User login form
- Basic input validation
- Responsive design
- Error messages for invalid input

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

---

## 🚀 How to Run
1. Open the folder (`WebDev-L2-Login-System`).
2. Double‑click `index.html` or open it in your browser.
3. Enter credentials to test the login system.
